# Отчёт о проделанной работе в рамках проекта "Система распределения задач между агентами для покупки билетов"

## Введение

В рамках проекта была разработана клиент-серверная система распределения задач между агентами для автоматизированной покупки билетов. Основной задачей проекта являлось создание системы, способной распределять заявки пользователей между несколькими агентами с учётом приоритетов, состояния агентов и динамического изменения очереди.

Проект реализован в виде веб-приложения с серверной частью, пользовательским интерфейсом, административной панелью, базой данных и системой агентов, взаимодействующих через WebSocket.

---

## Цель работы

Целью работы являлась разработка клиент-серверной системы распределения задач между агентами для автоматизированной покупки билетов. Система должна обеспечивать работу с заявками пользователей, распределение задач между агентами, управление приоритетами и обработку результатов выполнения задач.

* автоматического распределения задач.

# Работа агентов

Агент представляет собой отдельное консольное приложение.

После запуска агент:

1. Подключается к серверу по WebSocket.
2. Отправляет сообщение регистрации.
3. Начинает отправлять heartbeat каждые 30 секунд.
4. Ожидает получения задач.

После получения задачи агент:

* перебирает даты;
* эмулирует покупку билета;
* при успешной покупке отправляет результат;
* при отсутствии билетов сообщает о неудаче.

Для эмуляции используется:

* случайная задержка;
* вероятность успешной покупки 70%.

Также реализана обработка команды abort.

При получении abort агент:

* немедленно прекращает выполнение текущей задачи;
* не отправляет результат.

# Система приоритетов

Очередь заявок сортируется по:

1. admin_priority
2. user_priority
3. времени создания

Более приоритетные заявки обрабатываются раньше.

---

# Планировщик задач

Планировщик автоматически:

* получает список свободных агентов;
* получает очередь задач;
* назначает задачи агентам.

Если появляется более приоритетная задача и свободных агентов нет:

* менее приоритетная задача прерывается;
* задача возвращается в очередь;
* новая задача назначается агенту.
